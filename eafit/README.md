# EAFIT

Entregas de la fase académica (línea LE005, Diseño para el Servicio y la Experiencia). Sustentación final: segunda semana de noviembre de 2026. Al terminar, la carpeta se congela como `pre-kino/`.

## Estructura

Una carpeta por entrega, con fecha: `2026-11-12-sustentacion-final/`. Dentro van la fuente, el archivo entregado y una nota de qué rúbrica o plantilla aplica.

## Reglas

- Lo académico puede citar el producto. El producto nunca depende de lo académico.
- Lo que es solo exigencia del entregable (formato, extensión, rúbrica) se dice como tal y no se vuelve decisión de producto.
- Las entregas anteriores (decks del 19, 21 y 22 sep, entrega 2) están en `../pre-kino/`.
