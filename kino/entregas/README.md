# Entregas académicas

Entregables de la fase académica en EAFIT (línea LE005, Diseño para el Servicio y la Experiencia). Sustentación final: segunda semana de noviembre de 2026.

## Estructura

Una carpeta por entrega, con fecha: `2026-11-12-sustentacion-final/`. Dentro, la fuente, el archivo entregado y una nota de qué rúbrica o plantilla aplica.

## Reglas

- Lo que es exigencia solo del entregable (formato, extensión, plantilla, rúbrica) se dice como tal y no se convierte en decisión de producto.
- La presentación de diagnóstico no propone soluciones: cliente → evidencias → hallazgos → diagnóstico → pregunta guía → retos.
- Las entregas anteriores (decks del 19, 21 y 22 sep, entrega 2) están en `../../pre-kino/`.
