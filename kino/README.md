# Kino

El Kino nuevo: identidad de marca nueva, información más concisa. Lo de antes está en [`../pre-kino/`](../pre-kino/) y se usa como base.

| Carpeta | Qué va | Estado |
|---|---|---|
| [`canon/`](canon/) | Hechos, decisiones y vocabulario vigentes | Activo |
| [`investigacion/`](investigacion/) | Evidencia nueva y su síntesis | Vacío, listo para usar |
| [`marca/`](marca/) | Identidad nueva: estrategia, voz, visual, tokens | Por definir (ver D-002) |
| [`producto/`](producto/) | Flujos, reglas de negocio, pantallas, especificaciones | Vacío, listo para usar |
| [`codigo/`](codigo/) | Apps y paquetes | Vacío, listo para usar |
| [`entregas/`](entregas/) | Entregables académicos de EAFIT | Vacío, listo para usar |

**Cómo se lee.** Canon primero. Luego la carpeta del trabajo que vas a hacer. Cada una tiene su `README.md` con la estructura que espera y cómo se verifica lo que se hace en ella.

**Cómo fluye el trabajo.** La evidencia (`investigacion/`) sostiene las decisiones (`canon/`), las decisiones dan forma a la marca y al producto (`marca/`, `producto/`), y el código (`codigo/`) implementa lo que el producto especifica. Las entregas académicas (`entregas/`) toman de todas, pero ninguna depende de ellas.
