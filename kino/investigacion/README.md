# Investigación

Evidencia del Kino nuevo y su síntesis.

## Estructura

| Carpeta | Qué va |
|---|---|
| `observacion/` | Inspecciones directas del sistema o de la portería. Registros en JSONL, una observación por línea, con fecha y rol |
| `entrevistas/` | Guías, notas y citas anonimizadas |
| `mercado/` | Datos de mercado y competencia, cada uno con fuente web y fecha de consulta |
| `sintesis/` | Hallazgos, arquetipos e insights construidos desde lo anterior |

Se crean cuando hagan falta.

## Jerarquía de evidencia

Observado > entrevistas > brief y documentos académicos. Toda afirmación se marca como observada o inferida.
