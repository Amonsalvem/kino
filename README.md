# Kino

Plataforma de control de acceso para conjuntos cerrados. Este repositorio es el centro de trabajo de Kino: producto, marca, investigación, código y las IA que trabajan en ellos.

## Mapa

| Carpeta | Qué hay |
|---|---|
| [`kino/`](kino/) | El Kino nuevo: canon, investigación, marca, producto y código |
| [`kino/canon/`](kino/canon/) | Hechos, decisiones y vocabulario vigentes. Manda sobre todo lo demás |
| [`eafit/`](eafit/) | Entregas académicas. Se congela al terminar la fase EAFIT |
| [`herramientas/`](herramientas/) | Scripts compartidos sin marca |
| [`pre-kino/`](pre-kino/) | Archivo de la etapa anterior. Solo lectura |

## Cómo se trabaja

1. Las tareas se abren como **issues** en GitHub.
2. Cada tarea va en su rama y en un **PR en borrador**.
3. Nico propone. **Alejandro aprueba** en la revisión del PR e integra a `main`.

Las IA siguen [`AGENTS.md`](AGENTS.md). El detalle de nombres, ramas y commits está en [`CONVENCIONES.md`](CONVENCIONES.md).
